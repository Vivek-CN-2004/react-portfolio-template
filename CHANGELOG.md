# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-25

### Added
- Initial open-source release of the **React Portfolio Template**.
- Single centralized configuration file (`src/data/profile.js`) for personal details.
- Fully data-driven sections: Projects, Experience, Skills, Certifications, Navigation, Socials, and GitHub Stats.
- Interactive components: 3D card tilt (`react-tilt`), Framer Motion scroll reveals, typing animation, background particles, and animated counters.
- Integrated EmailJS contact form with client-side validation and toast feedback (`react-hot-toast`).
- Comprehensive documentation: `README.md`, `SETUP.md`, `CHANGELOG.md`, `LICENSE`, and `.env.example`.
- Pre-configured deployment setup for Vercel, Netlify, and GitHub Pages.
